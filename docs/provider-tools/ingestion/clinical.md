# High-Risk Ingestion Navigator clinical specification

## Intended population

Children with suspected button battery, multiple magnet, water bead, sharp
object, or esophageal food bolus ingestion in an emergency setting.

## Clinical purpose

Organize object-specific imaging views, elapsed-time capture, reviewed immediate
mitigation, consultation urgency, and removal or transfer preparation while
prominently escalating to Poison Control.

## Evidence baseline

- Poison Control button battery guidance.
- Object-specific toxicology, gastroenterology, surgery, ENT, and radiology
  guidance must be selected and versioned before implementation.

## Explicit non-goals

- No replacement for Poison Control, diagnosis, imaging interpretation, home
  observation decision, removal timing promise, medication dose, or procedure
  instruction.
- No product brand, patient identifier, or stored exposure record.

## Questions requiring clinical resolution

- Which imaging views and body regions are required for each object and age?
- Which elapsed-time, location, symptom, and co-ingestion states alter urgency?
- Which mitigation is age-, time-, swallowing-, and object-dependent?
- Which object combinations require surgery, GI, ENT, toxicology, or transfer?

## Required named reviewers

Medical toxicology and Poison Control, pediatric gastroenterology, pediatric
surgery, ENT, radiology, PEM, pediatric pharmacy, emergency nursing,
institutional policy, and regulatory review.

## Simulation acceptance cases

- A button battery case displays Poison Control and emergency consultation in
  the first interaction.
- A multiple-magnet case requests the correct imaging set and elapsed time.
- A water-bead case does not provide false reassurance from a negative plain
  radiograph.
- An unknown object preserves uncertainty and does not borrow a battery pathway.

## Release boundary

Remain Planned until every object pathway, mitigation condition, imaging set,
consultation threshold, pharmacy element, and simulation case is approved.
