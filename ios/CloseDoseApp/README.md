# CloseDose iOS App Skeleton

This directory contains SwiftUI source files that wrap the existing CloseDose website in a native iOS container. The app loads the static HTML exported in `Resources/index.html` using `WKWebView`, so the experience matches the responsive web version while giving you access to App Store distribution, native navigation controls, and the ability to expand with platform-specific features later.

## Project setup

1. Open Xcode and create a new **App** project that targets iOS 16 or later.
2. Name the project **CloseDose** and make sure the interface is **SwiftUI** and the language is **Swift**.
3. After the project is created, replace the autogenerated files with the contents of this directory:
   - Add `CloseDoseApp.swift`, `ContentView.swift`, and `WebContentView.swift` to the main app target.
   - Add `Info.plist` to the project (or merge its keys into your existing Info.plist).
   - Drag the `Resources` folder into the project and make sure "Copy items if needed" is checked so the bundled HTML ships inside the app.
4. Update the **Bundle Identifier** to match your team or organization in the Xcode project settings.

The resulting target can be built and run directly on the iOS Simulator or a device that has been provisioned for development.

## Keeping the in-app content updated

The `Resources/index.html` file is generated by building the existing website and copying the optimized HTML into the app bundle. Whenever the site changes, re-export the HTML from the web project (for example by running the existing static site build pipeline) and replace the file in this folder.

If you prefer to load the production site directly instead of bundling HTML, update `WebContentView` so that it uses a remote `URLRequest` pointing to `https://closedose.org`.
